# Google 로그인 버튼 자산

Google G 로고는 공식 브랜드 가이드가 제공하는 PNG 원본을 그대로 사용합니다.

- 가이드: https://developers.google.com/identity/branding-guidelines?hl=ko
- 원본: https://developers.google.com/static/identity/images/g-logo.png

로고의 색과 종횡비를 변경하지 않습니다. 버튼은 밝은 테마의 흰 배경, 1px #747775 테두리, 4px 모서리, 40px 기본 높이, 20px 로고, 12px 좌우 여백과 10px 로고 뒤 간격을 사용합니다. 글자는 #1F1F1F, Roboto Medium, 14px/20px이며 한국어는 글꼴 폴백을 사용합니다. 글자 확대 시 버튼 높이가 늘어납니다.

Roboto Medium은 Flutter SDK에 배포된 원본 파일을 `assets/fonts/Roboto-Medium.ttf`에 포함했습니다. 라이선스는 같은 폴더의 `LICENSE-Roboto.txt`에 있습니다. 글꼴과 로고는 실행 중 외부에서 다운로드하지 않습니다.
